El archivo StudentPerformanceFactors.csv obtenido de Kaggle fue modificado para fines educativos con el nombre StudentPerformanceFactors_extendido.csv.
Los datos no provienen de instituciones reales, se crearon para simular escenarios y analizar los factores de rendimiento estudiantil (https://www.kaggle.com/datasets/mosapabdelghany/student-performance-factors-dataset).
